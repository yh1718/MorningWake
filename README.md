# MorningWake 🌅

> 专为 macOS（针对 Mac mini M4 深度定制）打造的原生极简、平滑渐进式晨间音乐唤醒应用。

---

## 🌟 项目亮点

* 🎵 **平滑微步渐进淡入**：CoreAudio 底层以 100ms 高频微步进调谐，在设定时长内（默认 120 秒）平滑抬升至唤醒音量，完全消除突兀惊吓。
* 🎶 **多音源自由适配**：
  * **YouTube Music**：支持桌面客户端一键调起与模拟媒体键播放。
  * **Apple Music**：系统原生音乐 App 深度无缝调度。
  * **自定义本地音乐**：自由导入 MP3 / M4A / FLAC / WAV / AAC 等音频文件。
  * **离线和弦自然音**：内置柔和晨鸣音频作为安全兜底。
* 📅 **智能双轨作息与节假日调休自适应**：
  * **手机级双轨时间**：为工作日与周末独立设定唤醒时刻，支持周末慢晨推迟唤醒（如 09:30）或彻底静音休息。
  * **中国法定节假日与调休补班引擎**：内置节假日引擎，中秋、国庆、春节等假期自动跳过工作日闹钟，调休上班的周六日自动按工作日准时补响。
  * **日历状态与智能 Badge 提示**：菜单栏与设置面板直观呈现今日节假日状态（如 `中秋假期`、`调休上班`）与下次响铃类型标签。
  * 亦保留「每天」、「仅工作日」、「仅周末」与「自定义星期」传统排期供自由选用。
* 🖥️ **Mac mini M4 专属硬件感知**：
  * **点亮外接显示器**：利用 `IOPMAssertionDeclareUserActivity` 在响铃时破晓点亮外接显示器（如 DisplayPort / HDMI 监视器）。
  * **显示器调音避坑**：自动检测音频设备可调节性，智能绕过无法软件调音的显示器通道，强制锁定机载 `Mac mini 扬声器`。
  * **常电定时唤醒**：针对 Mac mini 交流常电特性，提供 100% 准时的休眠硬件预热唤醒，并自动防旧事件残留。
* 🔔 **锁屏交互与快捷键响应**：
  * 锁屏界面直接呈现交互式通知卡片：支持 **「我已清醒 (保持播放)」**、**「小睡一下」**、**「完全关闭音乐」**。
  * 菜单栏支持键盘快捷键：按 `Esc` 快速停止，按 `Enter` 快速清醒。
* 🔄 **音频输出无缝还原**：闹钟关闭后自动切回触发前的原音频输出设备（如显示器或耳机），无缝衔接日常使用。
* 🛡️ **安全熔断与干预检测**：
  * 30分钟无人应答安全熔断自动释放系统防休眠锁。
  * 渐变过程中用户轻按键盘 F11/F12 物理音量键即刻平稳平滑退出自动淡入，尊重人工介入。
* ⚡ **纯原生极致轻量**：采用纯 Swift + SwiftUI 原生编写，附带精美 macOS 原生 App 图标，开机自启常驻，内存占用仅约 20MB。

## 📥 下载安装 (Mac 专有 DMG 格式)

直接前往 [GitHub Releases](https://github.com/yh1718/MorningWake/releases/latest) 下载预编译安装包：
- **`MorningWake.dmg`**：推荐下载。双击打开后，将 `MorningWake.app` 拖拽到 `Applications`（应用程序）即可完成安装。
- **`MorningWake.zip`**：备用压缩包，解压后双击即可运行。

## 🛠️ 源码构建与运行 (开发者)

### 环境要求
- 操作系统：macOS 13.0 (Ventura) 及以上
- 推荐机型：Mac mini (Apple M4)
- 工具链：Xcode Command Line Tools / Swift 5.9+

### 一键构建打包
```zsh
git clone https://github.com/yh1718/MorningWake.git
cd MorningWake
chmod +x scripts/build_app.sh
./scripts/build_app.sh
```

构建产物位于 `build/MorningWake.app`。

### 运行单元测试
```zsh
swift test
```
覆盖核心 `FadeCurve` 渐变曲线运算、多排期筛选解析、硬件音频标签判定与小睡状态动态联动测试。

### 安装与自启
```zsh
# 复制到系统应用程序目录
cp -R build/MorningWake.app /Applications/

# 运行应用
open /Applications/MorningWake.app
```
打开应用后，在顶部菜单栏日出图标中点击「偏好设置」，开启「开机自动启动」即可。

## 📝 版本更新历史 (Changelog)

### [v2.0.0] - 2026-09-27 (里程碑大版本：双轨作息、节假日引擎与后台免点击播放)

* ⏰ **类似手机闹钟的灵活双轨作息**：
  * 支持为 **工作日**（如 07:30）与 **周末**（如 09:30）分别设置不同的唤醒时间。
  * 周末与假期作息支持一键开启或关闭；关闭时周末彻底静音，开启时享受推迟慢晨唤醒。
* 🇨🇳 **中国法定节假日与调休补班智能自适应**：
  * 新增 `HolidayManager` 离线节假日引擎，预置中国法定节假日与调休安排（覆盖元旦、春节、清明、劳动节、端午、中秋、国庆等）。
  * **法定节假日自动休假**：节假日当天自动按周末作息执行或静音，避免假期被工作日早起闹钟吵醒。
  * **调休补班日自动补响**：因放假调休而需上班的周六日，自动按工作日时刻唤醒，告别补班起晚误工。
* 🏷️ **菜单栏智能状态胶囊与今日日历属性**：
  * 菜单栏顶栏实时显示今日日历属性（如 `今天 · 中秋假期`、`今天 · 调休上班`）。
  * 下次唤醒时间旁动态呈现智能彩色 Badge（`💼 工作日`、`🏖️ 中秋假期`、`💼 调休上班`），响铃排期一目了然。
* 🎵 **YouTube Music 后台免点击原生直接播放引擎**：
  * 深度集成客户端原生 IPC 协议（`youtubemusic://play`），绕过 macOS 对后台或休眠应用的媒体按键截流限制。
  * 结合系统级 `reopen` 事件恢复最小化至 Dock 或隐藏的窗口，消除 Chromium 背景节能节流；通过多通道原生参数注入底层播放内核 `$9.playVideo()`，实现后台运行下 100% 免点击自动出声。
  * 播放指令绝对幂等（纯 Play 非 Toggle），彻底消除按键重复导致的误暂停问题；停止时采用 `youtubemusic://pause` 幂等安全纯暂停。
* 🖥️ **菜单栏显示结构重构与就地编辑**：
  * 宽度扩大至 360px 并重构核心卡片层次，根除特定显示设置下的时间截断；支持就地快速展开调整唤醒时刻。
* ⚙️ **偏好设置面板全新重构**：
  * 「定时与日程」重新设计，当选择「智能作息」时提供直观的分区调节卡片（工作日时刻、慢晨推迟开关与时刻、节假日调优开关、今日日历状态提示）。
* 🧪 **新增节假日引擎单元测试**：
  * 扩展 `MorningWakeTests`，包含法定假期识别、调休补班识别与双轨作息计算用例，10 项单元测试全部通过。

### [v1.1.0] - 2026-09-27 (体验升级版)

* 🎶 **多音源全面适配与就地试听**：
  * 新增对 **Apple Music**（系统音乐 App AppleScript 调度）与 **自定义本地音频文件**（支持 MP3、M4A、FLAC、WAV、AAC、AIFF、OGG）的深度支持。
  * 偏好设置面板新增音频「试听」、「停止」与「清除」控制，无需等待触发闹钟即可一键预览音质与音源。
* 🔌 **CoreAudio 硬件热插拔实时监听**：
  * 引入 CoreAudio 系统级属性监听器，当插入/拔出 3.5mm 耳机、连接蓝牙音频设备或外接显示器断开/重连时，实时自动刷新可用设备树与调音能力。
* 📅 **个性化日程与动态小睡卡片**：
  * 新增 **自定义星期** 模式（支持周一至周日独立勾选多选），满足任意非标准排班与作息。
  * 小睡时长支持 5 / 10 / 15 / 20 分钟自由配置，修改后锁屏通知卡片与横幅操作按钮（「小睡 X 分钟」）实时同步联动。
* ⚡ **电源管理时间边界与休眠防护**：
  * 增加休眠唤醒事件的时间边界检查：当距响铃过近（< 70秒）时智能跳过提前 60 秒的无效预热，防止注册过去时间点引发系统电源异常。
* 🛡️ **单元测试与无头防护体系**：
  * 新增 `MorningWakeTests` 单元测试套件，全面覆盖渐变曲线数学运算、多排期筛选解析、硬件音频标签与小睡状态联动测试。
  * 增加无头/CLI 测试环境识别防护（`isNotificationSupportedEnvironment`），杜绝因缺少宿主 Bundle ID 引发的通知调用崩溃。
* 🎨 **现代原生应用图标**：
  * 内置纯 CoreGraphics 矢量生成的高清破晓渐变 `AppIcon.icns`（16x16 至 1024x1024 完整支持），并同步配置为 DMG 磁盘卷专属图标。
* 🔔 **系统通知权限状态感知**：
  * 偏好设置中实时检测 macOS 通知授权状态，未授权时提供一键跳转系统设置引导。

### [v1.0.0] - 2026-09-18 (Mac mini M4 专享首发版)

* 🚀 **针对 Mac mini M4 架构深度定制**：纯 Swift + SwiftUI 原生打造极简轻量晨间唤醒应用，常驻内存仅约 20MB。
* 🎵 **CoreAudio 底层微步平滑淡入**：以 100ms 高频微步进调谐，支持平滑 S 曲线、对数感知曲线与线性递增曲线，彻底告别传统突兀惊吓闹钟。
* 🎶 **多策略音源与离线兜底**：支持调起 YouTube Music 客户端并模拟媒体键发声；内置离线自然和弦唤醒音频作为网络与客户端失效兜底。
* 🖥️ **外接屏幕破晓点亮与扬声器锁定**：
  * 通过 `IOPMAssertionDeclareUserActivity` 在响铃时破晓点亮外接显示器（DisplayPort / HDMI）。
  * 智能检测音频设备可调节性，自动绕过不可调音的显示器通道，强制锁定 Mac mini 机载扬声器。
* ⏰ **常电硬件休眠预热**：结合 Mac mini 交流常电特性，利用 IOKit `IOPMSchedulePowerEvent` 提前 60 秒硬件唤醒。
* 🔔 **锁屏交互式卡片**：在锁屏界面呈现原生通知卡片，支持「我已清醒 (保持播放)」、「小睡一下」与「完全关闭音乐」。
* 🛡️ **安全熔断与物理干预感知**：
  * 30分钟无人应答自动熔断释放系统防休眠锁。
  * 用户轻按物理音量键即可平稳退出淡入并保持当前音量。
* 📦 **自动化编译与 DMG 分发工具**：提供一键 Release 编译、Ad-hoc 签名与 DMG 镜像制作脚本。
